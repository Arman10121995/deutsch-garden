# Known Limitations

1. The bundled vocabulary bank contains 10,000 training cards. Their A1–C2 labels are curriculum decisions, not an official CEFR word-count table: CEFR provides no universal fixed vocabulary threshold, and the full deck has not been psychometrically calibrated against a certified learner population.
2. Placement uses a compact 36-item adaptive instrument and has not undergone psychometric norming against a large certified learner sample.
3. Listening uses synthesised German rather than studio-recorded multi-speaker audio. Since 3.9 native builds bundle a neural voice (Piper VITS, Thorsten, CC0) run on device through sherpa-onnx, so Android, desktop and Apple builds hear the same voice instead of whatever the operating system happens to have installed. The web build still uses a browser voice. It is a good narrator and still a single speaker: there is no dialogue between distinct voices, no regional accent and no spontaneous connected speech.
4. Writing evaluation is an offline transparent heuristic and cannot replace trained human scoring for advanced CEFR production.
5. **The speaking tutor is a scripted role-play, not a language model.** It follows a fixed sequence of authored turns and evaluates each reply with a deterministic rule engine. It will not improvise, will not answer a question you ask it, and will not follow you off-script. What it does reliably is tell you whether you addressed the turn, at sufficient length, using the target structures.
6. **Pronunciation scoring is text-based, not acoustic.** The lab compares the *recognised words* against the target sentence. It catches dropped words, wrong words, wrong endings and word-order problems. It cannot grade a single vowel or consonant, because no offline Flutter plugin provides forced phoneme alignment. A word transcribed correctly scores full marks even if the accent is heavy.
7. **Speech recognition is unavailable on Linux entirely.** `speech_to_text` has no Linux implementation, and there is no offline Linux recogniser bundled yet, so speaking practice on Linux is typed-only. Synthesis is no longer a problem there: since 3.9 Linux uses the same bundled neural voice as every other platform rather than shelling out to `spd-say` or `espeak-ng`.
8. The iOS artifacts CI produces are **unsigned**. The release includes an `.ipa`-shaped archive and the raw `.app`, but neither carries a provisioning profile or trusted signature; putting either on a device needs re-signing with your own Apple identity.
9. Speech recognition quality is the platform's, not the app's. On Android the system recogniser may route audio to the vendor's servers unless a German offline language pack is installed; on some devices and emulators no recogniser exists at all. Every speaking screen therefore accepts typed input as an equal path.
10. Free-talk scoring approximates coverage from answer length and connector use. It cannot verify that the content points were genuinely addressed — an off-topic answer of the right length and register will score well.
11. Stories are original graded texts written for this app, not authentic published literature. They are level-controlled rather than natural.
12. The SM-2 implementation uses conventional parameters rather than parameters fitted to this deck's review logs; it is a sound default, not a tuned model. **It cannot currently be tuned at all**: only aggregate per-item state is stored (`WordProgress`, `ActivityProgress`), never individual review events, so there is no history a modern scheduler such as FSRS could be fitted against. Adding a bounded append-only review log is the prerequisite for any scheduler work, and would also enable honest retention statistics and an undo for a misgrade.
13. Intervals are not fuzzed. Every card reviewed in one session comes due again on the same later day, so the deck tends to clump into peaks rather than levelling out. Anki randomises intervals by a few per cent for exactly this reason.
14. Achievements, quests and streaks are local. There is no leaderboard, no social feature and no server, so nothing here is comparable across users. There is also no cloud sync: moving a profile between platforms is a manual export/import, and the two copies diverge from the moment you continue studying on both.
15. Exam-prep mini mocks train task types and strategy but are not full-length official provider papers.
16. Real exam formats can change. Verify official provider pages before registration or final preparation.
