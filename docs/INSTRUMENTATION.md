# Instrumentation and Learning Metrics

DeutschGarden intentionally uses transparent metrics rather than opaque “AI level” claims.

- Vocabulary: per-card seen/correct/wrong/mastery/dueAt/favorite
- Grammar/listening/reading/writing/speaking: attempts + best score + completion
- Placement: last recommended CEFR band, overall attempted-item score and date
- Exam prep: objective mini-mock best score and attempts
- Global: XP, streak, daily reviews, overall vocabulary accuracy

No telemetry is transmitted by the included source.
