# Reference Sources

DeutschGarden content is independently authored. The following external materials are used only as framework/exam-format references.

## Council of Europe — CEFR

- CEFR overview and Reference Level Descriptions: https://www.coe.int/en/web/common-european-framework-reference-languages/reference-level-descriptions
- CEFR resources: https://www.coe.int/en/web/common-european-framework-reference-languages

Key design implication: CEFR itself is language-independent; language-specific Reference Level Descriptions can inventory words, forms and grammar by level. This is why DeutschGarden does not claim a universal official word count for each CEFR band.

## Licensing note

The app does not bundle third-party dictionary dumps discovered during research. This avoids silently imposing incompatible content licenses or weak CEFR-level assignments on the user’s project.
