# Privacy

DeutschGarden 3.0 is designed as a local-first app.

Stored locally:

- vocabulary mastery and due dates
- activity best scores and attempts
- writing drafts
- XP, streak and daily-goal counters
- theme/TTS settings
- most recent placement result

The source contains no analytics SDK, advertising SDK, user account system or remote database integration. German pronunciation is requested through the device TTS layer; actual voice implementation depends on the Android device and installed TTS provider.
