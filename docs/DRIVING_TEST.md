# German driving-theory practice

DeutschGarden includes a small, original offline Class B theory track. It is a
language-and-safety learning aid, not an official TÜV/DEKRA question bank,
driving school, legal service, or certificate issuer.

## What is included

- 72 original bilingual questions in eight subject areas;
- immediate-feedback topic practice with German-first text, an English helper,
  Previous and Skip;
- the existing local mistake bank for targeted repair;
- a 30-question mock with no answer reveal until submission;
- official-format context in the introduction: 30 questions, 110 maximum
  points, up to 10 error points, and failure after two wrong 5-point items.

The mock uses the error-point rule as a practice signal. Its questions are not
the official examination catalogue, and the displayed total is not an official
result. German licensing rules, signs and exam material can change, so learners
should verify current information with the responsible authority and a
qualified driving school before an examination.

The format reference is [FeV Anlage 7](https://www.gesetze-im-internet.de/fev_2010/anlage_7.html).
The safety explanations are written against the current [Straßenverkehrsordnung](https://www.gesetze-im-internet.de/stvo_2013/BJNR036710013.html);
the linked law, not this app, is authoritative when a rule changes.

## Offline and privacy design

All questions, translations and explanations are bundled source or assets. The
module makes no network request and adds no permission. Topic answers and mock
mistakes are stored only in the normal local profile and can be removed through
the app's existing progress controls.
