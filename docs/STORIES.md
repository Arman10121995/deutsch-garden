# Story mode

21 original graded stories containing 56 chapters across A1–C2.

## Grading

Each story is written to its level rather than simplified from a harder text:

| Level | What the prose does |
| --- | --- |
| A1 | Present tense, main clauses, high-frequency concrete vocabulary, 6–7 lines per chapter |
| A2 | Perfekt and Präteritum of common verbs, `weil` / `als` / `dass`, everyday narrative |
| B1 | Multi-clause narration, reported thought, Plusquamperfekt, opinion and reasoning |
| B2 | Nominalisation, extended attributes, passive, professional and technical register |
| C1 | Compressed syntax, abstract argument, register shifts, evaluative stance |
| C2 | Marked information structure, irony, ellipsis, dense nominal style |

## Reading features

- **Parallel translation** per line, switchable (and off by default in immersion mode).
- **Tap any word** for a lookup: the chapter glossary first, then the 10,000-card
  vocabulary deck. A matched word can be pushed straight into the review deck.
- **Adjustable type size** from 14 to 26 pt.
- **Listen to the chapter** through German TTS.
- **Per-chapter glossary** of the items most likely to block comprehension.
- **Comprehension check** after each chapter; wrong answers go to the mistake bank.

## Progress

A chapter counts as finished at 70 % on its comprehension check. Chapter
completion feeds `storyProgress(level)`, the `storyChapters` achievement metric
and the "read a chapter" daily quest.

## Honesty note

These are original texts written for this app. They are level-controlled, which
means they are *not* authentic published German — authentic text at B1 is
usually harder than a B1 graded reader. Use them to build reading stamina, then
move to real material.
