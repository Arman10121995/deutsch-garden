# Generated vocabulary-scene sources

`vocab_scene_sheet_02.png` was generated specifically for DeutschGarden with
OpenAI's image-generation tool on 2026-09-02, then reviewed and cropped by
`tool/crop_vocab_scene_sheet.py`. It contains no source photograph, logo,
watermark or text. The resulting 16 runtime tiles live in
`assets/vocab_generated/` and are distributed as project assets under MIT.

Tile order: kaufen, bezahlen, fragen, antworten, helfen, warten, suchen,
finden, reisen, telefonieren, lernen, arbeiten, feiern, treffen, krank,
gesund.

Prompt:
